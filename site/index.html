Circadian rhythm · a personal time tracker

Your hours, in one file you own.

Cirrhy tracks time against clients, projects and tasks, and keeps every record in a single readable document in a folder you choose. No account, no server, no network code — sync it with whatever you already trust.

The loop

Start, stop, and pick up where you left off.

The running timer sits above your recent work. Every past entry has a run button that starts a new timer from it — the tap you make twenty times a day.

Sync is your choice

Put the folder in iCloud Drive, Dropbox, Nextcloud or Syncthing. Cirrhy talks to none of them.

  • Read, merge, write. Every save merges into what is on disk now, never blindly overwrites it.
  • Per record, not per file. Two devices edited between syncs is the normal case, not a conflict dialog.
  • Losers are demoted, not destroyed. The older side of a conflicting edit moves into that record's history.
  • Deletions stay deleted. Tombstones stop a stale copy from resurrecting what you removed.
  • One timer per device. Two timers left running are shown for you to reconcile, never silently swallowed.

One file, and it is yours

There is no export button, because there is nothing to export from.

The document is plain JSON with a published schema. Open it, back it up, script it, or hand it to an AI agent for the report the app does not have.

Readable

One cirrhy.json per folder. UUIDs, UTC timestamps, nothing encoded or encrypted.

Documented

A JSON Schema and an agent-facing format guide ship in the source, so imports and reports go through the file.

Recoverable

Backups before any write that cannot be atomic, plus Back up now whenever you want one.

Auditable

Apache 2.0. Every line that touches your data is public on GitHub.

Privacy

Collects nothing, because it has no way to send anything.

Data Not Collected

The same answer Cirrhy gives on its App Store privacy label, for every category.

NoNetwork requestsThe app contains no networking code at all.
NoAccounts or sign-inThere is no identity of any kind to create.
NoAnalytics or crash reportingNothing measures how you use it.
NoTracking or advertisingNo third-party SDK that collects anything.
The only identifier is a random UUID minted on first run, stored in your own file so two devices' timers do not collide. Read the privacy policy.

Everywhere you work

One document, every device.

The same file opens on each of them. Windows is built but not yet tested by anyone — reports welcome.
